# 판정: S18 PASS.
#   - 1단계 Esc: `첫 단계입니다. 취소하려면 Ctrl+C를 누르세요.`가 나오고 1단계에 머문다. 1단계 footer에는 `Esc 뒤로`가 없다.
#   - 3단계 Esc: 2단계로 돌아가고, 앞서 바꾼 커밋 언어(English)가 미리 선택돼 있다. 다시 3단계로 가면 요약이
#     `언어 설정: 주석 en · 커밋 en · AI 응답 ko`로 그대로다.
#   - header·요약·footer: 화면 맨 위 `init · 모델 구성 › 구성 편집 › Claude Code › 에이전트별`, 그 아래 `지금까지 고른 값`,
#     맨 아래 `방향키 이동 · Enter 선택 · Esc 뒤로 · Ctrl+C 취소`.
#   - 줄인 요약: 에이전트를 많이 답하자 요약 첫 줄이 `  … 외 3개`, 이어서 `  … 외 5개`로 바뀌고 header는 화면 맨 위에 남는다.
#   - 확인 블록 세 묶음: ` 답한 값` / ` 바뀌는 설정` / ` REA`, 그 아래 `이대로 진행할까요?`와 `적용`·`뒤로`·`취소`.
#   - `뒤로`는 구성 단계(`구성을 바꿀까요?`)로 돌아가고, 유지 뒤 같은 확인 화면이 다시 나온다. `취소`는 `  init cancelled.`.
#   - 취소 뒤 `--- ls -A` 아래가 비어 있다(아무 파일도 쓰지 않음).
#   - 두 번째 init은 적용되고 `--- ls -A` 아래에 생성 파일이 찍힌다.
#   - update: 메뉴 Esc에 첫 단계 안내, Codex 탭 Esc로 도구 선택(`Codex` 커서)으로 돌아옴, Ctrl+C 뒤 `exit=1`(0이 아님).
#
# 참고(판정에 영향 없음):
