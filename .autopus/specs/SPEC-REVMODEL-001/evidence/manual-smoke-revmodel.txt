#   - doctor의 리뷰 provider readiness 줄: claude·codex·gemini 모두 `ready`.

# D-1 (편차): 체크리스트 2단계의 gemini model 전환을 하지 못했다.

#   (증명된 다른 google model이 없음). 그래서 "바꾼 값 -> 확인 호출 -> 적용 -> 되돌림" 경로는 judge를 바꾸는 것으로
#   대신 확인했다. 따라서 S15 Then의 "바뀐 orchestra.providers.gemini.model 줄"은 이 기록에 없고, 그 자리에
#   `spec.review_gate.judge claude → codex`(적용)와 `codex → claude`(되돌림) 줄이 있다.
#
# doctor FAIL (smoke 뒤 수정됨): 42-doctor.txt의 FAIL은 OMP `rpc.*` capability 다섯 줄이 `exit_nonzero`였기 때문이다.
#   원인은 OMP 18.3.0이 `hub` 도구를 없앴는데 RC의 provider-free 준비 검사가 `--tools task,hub,todo`로 RPC를 띄운 것이다
#   (omp 18.6.1은 `Unknown tool in --tools: hub.`로 RPC 전에 끝난다). v0.50.126에서 f1d81cd9
#   (`fix(omp): provider-free 준비 검사가 OMP 18.3 이후에서도 RPC를 띄운다`)가 검사를 `--tools task,todo`로 줄였다.
#   같은 doctor의 `omp.context.*` ERROR 줄(receipt_missing 등)이 이 수정으로 함께 사라지는지는 이 smoke에서 다시 보지 않았다.
#   리뷰 provider readiness 줄은 이 FAIL과 별개로 모두 ready다.
